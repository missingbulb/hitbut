# product-requirements

The human-reviewed sink: research from the wikis distilled into product
requirements. This is the **only** `product-wiki/` content the rest of the repo
may reference.

## Rules for this folder

- **Human-reviewed only.** No growth pass writes here. A finding reaches this
  folder because a person read it, judged it, and decided it constrains the
  product.
- **A requirement here is not the executable spec.** The executable spec lives at
  `dev/requirements/requirements.md`; entries here are the reviewed input that
  spec is written from.
- **Every entry cites the wiki page it came from**, so the evidence behind a
  requirement stays reachable.

None yet. This folder is seeded empty by design — nothing can be distilled until
